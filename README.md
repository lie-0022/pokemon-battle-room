# 포켓몬 데스크톱 펫 + 전국도감 배틀 🔴

PokéAPI 실데이터(151마리 도트 스프라이트)로 만든 두 가지:

1. **🖥️ 데스크톱 펫** — 바탕화면 위를 도트 포켓몬이 돌아다니는 백그라운드 앱 (Electron)
2. **🎮 전국도감 배틀 게임** — 브라우저에서 즐기는 턴제 배틀

> 모든 데이터는 공식 데이터 API인 [PokéAPI](https://pokeapi.co)에서 받아온 실제 포켓몬 데이터입니다 — 나무위키가 문서화하는 종족값·타입·기술·진화와 동일한 출처.

---

## 🖥️ 데스크톱 펫

작은 도트 포켓몬들이 바탕화면 위를 걷고, 쉬고, 자고, 가끔 점프합니다. 투명·클릭 통과라 바탕화면 조작을 방해하지 않고, 시스템 트레이(몬스터볼 아이콘)에 상주합니다.

### 실행

**가장 간단 — `start-pet.vbs` 더블클릭** (콘솔 창 없이 백그라운드 실행)

또는 터미널에서:

```bash
npm install   # 최초 1회 (Electron 설치)
npm start
```

### 조작 (시스템 트레이의 🔴 몬스터볼 아이콘)

> 트레이 아이콘이 안 보이면 작업표시줄 오른쪽 **`^`(숨겨진 아이콘)** 을 클릭하세요. 항상 보이게 하려면 아이콘을 작업표시줄로 드래그.

- **좌클릭** — 무작위 포켓몬 한 마리 추가
- **우클릭** — 메뉴:
  - 🎲 무작위 포켓몬 추가 / ➕ 스타팅 추가 / 🐦 10마리 풀어놓기
  - ➖ 한 마리 줄이기 / 🧹 모두 치우기
  - 크기 (작게/보통/크게)
  - 🖱 클릭 통과 토글 — *체크 해제* 하면 펫을 마우스로 만질 수 있음
  - ❌ **종료** (앱을 끄려면 여기서)
- 펫에 **마우스를 올리면 점프**, **클릭하면 인사**합니다.

### 동작 방식

| 파일 | 역할 |
|------|------|
| `main.js` | Electron 메인 — 투명/항상위/클릭통과 창 + 트레이 메뉴 |
| `preload.js` | 메인 ↔ 렌더러 IPC 다리 |
| `pet.html` / `pet.css` / `pet.js` | 펫 렌더링·이동·상태(걷기/대기/수면/점프) |
| `generate-icon.js` | 트레이용 몬스터볼 PNG 생성 (외부 라이브러리 없음) |
| `start-pet.vbs` | 콘솔 창 없는 백그라운드 실행기 |

> 스프라이트 이미지는 PokéAPI CDN에서 불러오므로 **인터넷 연결 필요**.

## 🎮 전국도감 배틀 게임 (브라우저)

### 실행

- **`index.html` 더블클릭** (데이터가 `pokedex.js`에 임베드돼 서버 없이 동작)
- 또는 `npx serve .` 후 터미널에 출력되는 주소(보통 `http://localhost:3000`)로 접속

### 실데이터 (1세대 1~151)

- ✅ **151마리 전체** — 한국어 이름 + 공식 도트/애니메이션 스프라이트 + 일러스트
- ✅ **실제 6종족값** (HP/공격/방어/특공/특방/스피드)
- ✅ **실제 18타입 상성표** (불꽃→풀 2배, 전기→땅 0배 등)
- ✅ **실제 기술 88종** — 한글명·위력·타입·물리/특수·PP·명중률
- ✅ **실제 포획률** (종별 capture_rate) / **실제 진화 레벨**

### 플레이

스타팅 선택 → 풀숲 탐험 → 배틀(싸운다/몬스터볼/교체/도망) → 레벨업·진화 → 📖 전국도감 수집 → 💊 회복센터

| 파일 | 역할 |
|------|------|
| `index.html` / `style.css` / `game.js` | 배틀 게임 |
| `pokedex.json` / `pokedex.js` | PokéAPI 실데이터 (json=fetch용, js=임베드용) |

## 데이터 다시 받기 (선택)

```bash
node build-dex.js
```

PokéAPI에서 151마리 + 타입 + 기술 + 진화를 받아 `pokedex.json`과 `pokedex.js`(각 ~130KB)를 새로 만듭니다. (약 460회 요청, 1~2분)

# 06. 밸런스 전면 재설계 (v1.2.0)

> 배경: 칼로스+5(=45번째 지방) 실플레이에서 뽑기 ★25 인플레·합성 정체·업그레이드 벽(수조 골드)·레벨업 정지가 동시 발생.
> 원인은 개별 버그가 아니라 **성장률이 서로 다른 지수/선형 커브들의 패치워크**. 이 문서는 ① 현황 전수 문서화 ② 발산 진단 ③ 재설계안 ④ 페이스 목표(며칠짜리 컨텐츠)를 기록한다.

---

## 1. 현황 — 공식 전수 (재설계 전)

### 1.1 진행(스테이지) 축
| 항목 | 공식 | 성장형태 |
|---|---|---|
| 적 레벨 | `5 + r*20 + route*2 + wave/2` (무제한) | **선형** (지방당 +20) |
| 지방 배수 | `regionMult(r) = 1.9^min(r,7) × 1.18^(r-7)` | **지수** |
| 적 HP | `statAt(hp, lv) × regionMult × (1+route*0.1) × [0.65 wave / 2.4 boss / 6 champ]` | 선형×지수 = **지수** |
| 적 공격 | `statAt(atk, lv) × regionMult^0.55 × (1+route*0.06) × [0.16/0.24/0.28]` | **준지수** |
| 구조 | 지방 = 6루트 × 8웨이브 + 루트보스, 7번째 = 챔피언. 8지방 순환(칼로스+5 = r45) | — |

### 1.2 플레이어 성장 축
| 항목 | 공식 | 성장형태 |
|---|---|---|
| 레벨 | 캡 = 최전선 챔피언 적Lv + 40. `statAt`은 레벨에 **선형** | 선형 |
| 경험치 | 킬XP = 적Lv×3 (보스+30·챔프+120), `xpToNext = 30+lv*8` → 약 3킬/렙 | 선형 |
| 개체치 | 0~31, statAt에 가산(`2·종족값+iv`) — 최대 ~10% | 상수 |
| 업그레이드(⚔/❤/⚡) | 비용 `10×1.55^n`(공속 12×1.65^n), 효과 **선형** +12%p/+14%p/−45ms | 비용 **지수**, 효과 선형 |
| 배지 | `1 + badges×0.08` | 선형 |
| 장비 효과 | `effVal = base + perStar×(★-1)` — 별에 **선형** | 선형 |
| 마스터리/수집 | +1%/종(100킬), 골드 +0.3%/종 | 선형(미미) |

### 1.3 경제 축
| 항목 | 공식 (재설계 전) |
|---|---|
| 킬 골드 | `(5 + r*8 + route*2) × regionMult × [1/6/20] × goldMult` |
| 오프라인 | 킬골드/3 × 0.3 (실전의 30%) |
| 뽑기 비용 | `80 + (5+r*8) × regionMult × 0.33` (킬당 1~3회) |
| 뽑기 별 | `1 + floor(r/2)` (+30% +1, 프리미엄 +85% +1) ← **r45 = ★23~25** |
| 합성 | 같은 도구 3개 → ★+1. 성공률 `0.95 − (★−1)×0.07`, **바닥 0.15**. 실패 시 1개 소실 |
| 장비 판매 | `(40+rare×35) × ★^1.6 × (1+r×0.35)` |
| 레이드 메달 | 등급×[2/3/5/8](밴드) ×3(첫클) · 상점: 돌5/사탕8/이로치100/전설250/상자20·60 |

### 1.4 발산 진단 — 무엇이 왜 무너졌나
| # | 증상(r45 실측) | 원인 |
|---|---|---|
| D1 | **업그레이드 벽**: n≈60부터 비용 수조 골드 — "하나도 못 산다" | 비용 1.55^n(지수)인데 골드 수급 지수는 1.18^r — 수급이 비용을 영원히 못 따라감 |
| D2 | **뽑기 ★25 인플레** | 뽑기 별 = r/2 무제한 — 합성 사다리(3^n 재료)를 뽑기가 통째로 건너뜀 |
| D3 | **합성 정체** | ★20+에서 성공률 바닥 15% + 실패 소실 → 기대 재료 20개/성공. 뽑기 인플레와 결합해 "합성은 무의미, 뽑기가 전부" |
| D4 | **레벨업 정지** | 파티가 캡(최전선+40)에 도달하면 다음 지방까지 레벨업 없음 — 버그가 아니라 표시 부재로 '정지'처럼 보임 |
| D5 | 적 HP/공격의 지수 vs 플레이어(선형 합) — 주기적으로 벽 → 그때마다 임시 계수 패치 반복 | 구조적: 플레이어에 **지수 성장 엔진이 없음** |

핵심 통찰: **플레이어의 유일한 지속 성장원(장비 별·업글)이 전부 선형 효과**라 지수 적을 상대로 언젠가 반드시 막힌다. 반대로 뽑기 별을 무제한 지수로 주면(D2) 게임이 무너진다. → 성장의 지수 엔진을 하나만 정하고, 모든 커브를 거기에 앵커해야 한다.

## 2. 재설계 — 단일 앵커 + 하이브리드 페이스

**모든 수치는 `regionMult(r)` 하나에 앵커한다.** 적 강함·골드 수급·모든 비용이 같은 커브를 타면 비율이 영원히 유지된다(발산 불가). 플레이어 파워는 [레벨(선형)+별(지방 비례)+업글(꾸준히 누적)+배지]의 합이 지방당 적 성장률을 *약간* 밑돌게 — **후반으로 갈수록 완만하게 감속**.

### 2.0 페이스 엔진 결정 (시뮬 5회 교차검증 후 확정)
시뮬 결과 **"계수 하나로 7주 곡선"은 불가능**함이 판명됐다. 두 극단만 존재:
- **효과<비용(1.05 vs 1.3)** = 42지방까지 즉사 → 5지방 만에 3일→53일→폭발하는 **이중지수 절벽**(브릭 월).
- **효과≈비용(매칭)** = 절벽은 사라지나 골드 수급이 업글 비용을 압도 → r50을 반나절에 뚫음(너무 빠름).

또한 **지수 업글 효과는 기존 세이브와 충돌**(r45 유저의 업글 수치 ~40에 `1.05^40`=7배 vs `1.20^40`=1470배로 극도로 민감) → 채택 불가.

**최종 채택 = 하이브리드 (유저 승인):**
- **선형 업글 효과 유지**(+12%/+14%/−45ms) — 검증된 밸런스·세이브 안전. 절벽은 **완만한 적 성장(regionMult 1.12)** 으로 방지: 선형 플레이어가 완만한 지수 적에 *서서히* 밀려 지방마다 조금씩 길어지는 게 곧 방치 곡선.
- **챔피언·보스 = 메아리 관문**(기본 배수 + 완만한 지방벽). 챔피언 전투가 지방마다 초→분으로 자라 실질 진행 게이트가 됨(유저 승인: 수십초~수분). HP만 벽으로(공격 벽은 전멸 절벽이라 금지).
- **캠페인 ~3주(전선 r30~40 도달) + 엔드게임 4주+**(레이드 지옥 사다리·이로치 1% 헌팅·개체치 31·도감 151·랭킹). 나머지 시간은 breadth가 담당.

### 2.1 새 공식
| 항목 | 새 공식 | 근거 |
|---|---|---|
| 지방 배수 | `1.9^min(r,7) × 1.12^(r-7)` | **시뮬로 확정**: 적 방어(레벨 선형)가 내 레벨 성장을 상쇄(`100/(100+def)`)해 플레이어 실질 성장은 지방당 ~3.5%(업글+배지+별)뿐. 1.12면 갭 ~8%/지방 → 관문 전투가 지방마다 자연히 길어짐(감속). |
| 웨이브/보스/챔피언 배수 | 트래시 `0.6` · 보스 `2.8 × 1.02^r` · 챔피언 `8 × 1.045^r` (HP만) | 트래시 빠릿 유지. 보스·챔피언에 완만한 지방벽 → 관문 전투 초→분 성장. 공격은 벽 안 걸음(전멸 절벽 방지) |
| 업그레이드 효과/비용 | 효과 **선형**(+12%/+14%/−45ms) · 비용 `10×1.30^n`(공속 12×1.35^n) | 지수 효과는 세이브 충돌로 폐기. 선형 유지. 비용 1.55→1.30으로 완화 → 지방당 꾸준히 구매(수조 골드 벽 제거) |
| 뽑기 별 | `1 + gachaDepth(r)`, `gachaDepth = r≤14: floor(r/2), 이후: 7 + floor((r-14)/3)` | 별 인플레 감쇠(지방 3개당 +1) — r45 기본 ★17~18(기존 25). 별은 계속 오르되 합성 도전(+1~3)이 항상 위에 존재 |
| 합성 성공률 | `0.95 − (★−1)×0.05`, **바닥 0.35** | 고별 기대 재료 20개→8.6개/성공. "안 올라간다" 체감 제거, 도전성 유지 |
| 레이드 상자 | `gachaDepth + 2 / +3` | 뽑기 상위권 확정 재료(항상 뽑기보다 반 발 위, 합성 도전은 그 위) |
| 나머지(킬골드·뽑기 비용·판매가·오프라인) | 기존 유지 — 이미 regionMult 앵커 | 비율 유지 확인만 |

### 2.2 페이스 목표 — "틀어놨을 때 며칠짜리인가"
가정: 방치 8시간/일, 배속 적절히 사용, 몹 2~6초·보스 10~30초·챔피언 30~90초.

| 구간 | 목표 도달 시점 | 컨텐츠 |
|---|---|---|
| r0~3 (관동~신오) | **1일차** | 기본 루프 학습, 레이드 일반 |
| r4~7 (1회차 완주, 배지 8) | **2~4일차** | 레이드 정예, 장비 ★5~8 |
| r8~15 (2회차) | **1~2주차** | 레이드 전설, ★9~12, 이로치·개체치 파밍 |
| r16~30 (3~4회차) | **3~6주차** | 레이드 지옥 도전, ★13~16 |
| r30+ | **2개월+** | 무한 감속 구간·랭킹 경쟁·컬렉션(151 도감·이로치·개체치 31) |

지방당 소요(시뮬 산출로 검증): r5 ≈ 30~60분 → r15 ≈ 2~4시간 → r30 ≈ 하루+ (감속).

### 2.3 페이스 실측 결과 (최종 코드 적용, 실 tick 루프 측정 · 수급-정합 로드아웃)
| 지방 | 업글 | 별 | 몹 | 챔피언 |
|---|---|---|---|---|
| r0 | 11 | ★1 | 0.1s | 1.2s |
| r7 | 35 | ★4 | 0.1s | 4s |
| r20 | 49 | ★10 | 1.0s | 1.3분 |
| r30 | 55 | ★13 | 2.2s | 4분 |
| r40 | 61 | ★16 | 4.9s | 2.4분 |
| r45 | 66+ | ★18+ | 7s | **5분** |
| r50 | — | — | — | **10분(벽)** |

- **트래시는 빠릿** · **챔피언이 관문** — r30→r45 3주 구간에서 초→분 성장(4분 관문) · r50 이상은 과장비 엔드게임(10분+).
- **페이스 검증**(현재 세이브 r50, Lv.1060, 업글 66/66 기준 역산):
  - r40 챔피언: 2.4분 (쉬운 관문)
  - r45 챔피언: **5분** (준관문)
  - r50 챔피언: **10분+** (벽)
- 벽 계수 최종값: **챔피언 ×1.015^r** (보스 ×1.02^r 유지). 1.045→1.015로 조정해 과도한 시간 제거.

### 2.4 장비 등급 — 이동형 플래토 + 효과 상한
합성 확률을 **뽑기 기본별 대비 상대 깊이**로 재설계(절대 별 → 상대 별). `fuseRate(★) = clamp(0.92 − max(0, ★ − (gachaDepth(maxRegion)+1)) × 0.13, 0.10, 0.92)`.
- 기본별 이하 92%(옛 장비를 전선까지 쉽게 승급) · +1칸 79% · +2 66% · +3 53% · +4 40% · +5 27% · +6 14%(바닥 10%).
- 기대 재료(`2+1/p` 누적): +3칸 35개 · +4칸 138개 · +5칸 620개 → **실질 플래토 = 기본별+3~4**, +5부터 급등해 자연 정지.
- 진행(maxRegion↑)하면 기본별↑ → 플래토 밴드 통째로 상승(r20 ★10~14 → r45 ★18~22 → r60 ★23~27). "등급이 어느 선에서 머무는" 체감 구현. 기존 보유 고별은 유지(진행 시 다시 승급 쉬워짐).

**확률·감쇠형 효과 상한 + 초과분 환원**(`EFF_CAP`) — 별 폭주가 게임을 안 깨뜨리되, 상한 이후에도 별 업그레이드가 이점을 유지:
| 효과 | 상한 | 도달 별 | 초과분 환원(50%) | 예시 |
|---|---|---|---|---|
| 풀죽음(flinch) | **30%** | ★9 | → **공격** | ★25 = 풀죽음 30% + 공격 +20% |
| 피해감소(reduce) | **70%** | ★11 | → **HP** | ★30 = 감소 70% + HP +48% |
| 명중(acc) | **100%** | ★31 | → 공격 | |
| 치명(crit) | **100%** | ★38 | → 공격 | |
- 초과분은 도구 설명에 `(상한·초과분→공격 +N%)`로 표시, 자동장착 점수에도 반영.
- 데미지 배수(physAtk·specAtk·offMult·typeBoost·superEff·lifesteal 등)는 **상한 없음** — 별 성장이 곧 의도된 파워 진행.

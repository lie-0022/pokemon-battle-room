# 배틀룸 재설계 — 아키텍처 & 단계별 구현 계획

> 기반: [`01-TBH-레퍼런스-리서치.md`](01-TBH-레퍼런스-리서치.md)
> 목표: 단조로운 1:1 자동전투를 → **TBH식 다층 성장 루프**(파티·진행 벽·영구 메타·수집)로 재설계.
> 방식: **하나씩(phase by phase)**. 각 phase는 독립 실행·테스트 가능하게.

---

## A. 새 아키텍처 원칙

1. **상태(state) 중심**: 모든 진행은 `state` 객체 1개에 모이고 `localStorage`에 저장(`pkmnRoom_v2`).
2. **시스템 분리**: 전투/렌더/상점/저장/진행을 함수 그룹으로 분리(파일은 당장은 `room.js` 단일, 필요시 분할).
3. **데이터는 pokedex.json**: 종족값·타입·기술·진화·스프라이트 전부 실데이터.
4. **점진 확장**: 각 phase가 state에 필드를 추가해도 이전 세이브와 충돌 없게(버전·기본값 처리).

## B. 목표 상태 모델 (최종형, phase별로 채워감)

```js
state = {
  version: 2,
  gold: 0,
  candy: 0,                 // 희귀재화(강화·합성용) — Phase 5
  party: [ {en, lv, xp, hp?} , ... 최대 3 ],   // 실제 전투원 — Phase 1
  bench: [ ... ],           // 후보 포켓몬 보관 — Phase 5
  up: { atk, hp, spd },     // 즉시 업그레이드(골드) — 유지
  progress: {               // 진행 — Phase 2
    region: 0, route: 1, wave: 1, best: 1,
    badges: [], beaten: []  // 체육관/사천왕 클리어 기록
  },
  trainer: { points, nodes: {} },   // 계정 영구 트리 — Phase 3
  dex: { caught: {} , kills: {} },   // 도감/처치수(펫훅) — Phase 5
  settings: { autoHeal, autoAdvance },  // 마찰 제거 — Phase 6
  lastSeen: 0,
}
```

## D. 단계별 구현 계획 (체크리스트)

### ✅ Phase 1 — 파티 3마리 동시 전투 (이번 작업)
- state v2 도입, party = 실제 전투원 배열(최대 3)
- 3마리가 동시에 적을 자동 공격(각자 쿨다운/스탯), 적은 **선두(front)** 를 우선 타격
- 선두 기절 시 다음 포켓몬이 전열로, 전멸 시 회복 후 재시작
- 처치 시 전원 경험치/골드, 레벨업·진화 유지
- 업그레이드(공격/체력/속도/회복) = 파티 전체 적용, **영입 = 실제 전투원 추가**
- **완료 기준**: 3마리가 같이 싸우고, 선두 교대·전멸 복구·레벨/진화/업그레이드가 정상.

### ✅ Phase 2 — 진행 구조 (루트·보스·챔피언·지방) — 완료
- 지방(8) → 루트(지방당 6) → 웨이브(루트당 8) → **루트 보스** → **챔피언** → 다음 지방(난이도↑)
- 챔피언 격파 시 **🎖배지** 획득 = **파티 영구 +8% 공격·체력**(부분적 영구진행)
- 지방마다 적 스탯 ×1.9 스케일, 보상도 비례 증가
- **완료 기준 충족**: 진행에 목표(루트 클리어)·벽(보스/챔피언)·난이도 상승 생김.

### ✅ Phase 3 — 계정 영구 진행 (트레이너 트리) — 완료
- 새 재화 **🍬사탕**(루트보스 +1, 챔피언 +5)으로 찍는 **트레이너 능력 트리 패널(🌳)**
- 노드: 공격·체력 마스터리(+5%/Lv), 골드·경험치 부스트(+8%/Lv), 치명타(+2%/Lv), **4번째 동료 슬롯**
- 배지(영구 +8% 공/체) + 트리 = 리셋해도 남는 영구 메타 진행 2축

### ✅ Phase 4 — 전투 깊이 (기술 + 상성 + 상태이상) — 완료
- 각 포켓몬이 **실제 기술**(pokedex.json)을 순환 시전 — 기술 타입으로 상성·STAB(자속 1.5×) 적용
- **상태이상 5종**: 화상🔥(도트+공격↓)·마비⚡(행동 실패)·빙결❄️(행동불가)·독☠️(도트)·수면💤(행동불가)
  - 기술 타입에 따라 16% 확률 부여(불→화상, 전기→마비, 얼음→빙결, 독→독, 풀→수면), 스프라이트 틴트+뱃지
- **완료 기준 충족**: 평타→기술/상성/상태이상 전투로 전환.

### ✅ Phase 5 — 수집·강화 (도감 훅 + 사탕 트리) — 완료
- **도감 패널(📖)**: 처치한 종 기록(처치수 표시), 종마다 100킬 → **마스터🌟**
- **수집 보너스**: 고유 종당 골드 +0.3%, 마스터 종당 공격 +1% (TBH의 "5,000킬 펫" 훅 축소판)
- **강화**: 사탕 트리(Phase 3)가 강화 축 담당
- (확장 여지: 동일 포켓몬 합성/별등급, 레어리티 장비 — 추후)

### ⬜ Phase 6 — 마찰 제거 & 폴리시
- 자동 회복/자동 진행/빠른 이동, 오프라인 보상 강화, 연출·사운드
- **완료 기준**: 손 안 대도 쾌적하게 굴러감.

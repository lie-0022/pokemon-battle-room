## ② 디시 인디게임 갤러리 (id=indiegame) — 1회만

> 필독 공지 준수: 장르+루프 한 줄 / 움짤 3~8초 2~3개 / 실스샷 3~6장 / 개발자 신분 공개 / 고생담·감성팔이 금지

**제목:** 포켓몬 1세대 방치형 오토배틀러 만든 개발자임

```
장르: 방치형 오토배틀러 (Task Bar Hero식 화면 하단 도킹형)

한 판 흐름: 파티 3마리가 자동전투로 웨이브 클리어 → 루트 보스 → 지방 챔피언 →
다음 지방. 방치하면 골드가 쌓이고 그걸로 업그레이드·장비 뽑기·합성해서 더 깊은
지방을 뚫는 루프임.

동종 장르랑 다른 점:
- 포켓몬 1세대 151마리 실데이터 (종족값·18타입 상성·기술, PokéAPI)
- 온라인 랭킹 내장 (스테이지 진행 / 레이드 타임어택, 주간 보드)

- 일일 미션·스트릭 같은 방치형 표준 요소

윈도우/맥, 한국어+영어, 무료 비영리 팬게임임 (수익화 없음)

드라이브: https://drive.google.com/drive/folders/1dROIj9Za1kNMdmcaPJljL209immLuMIk?usp=sharing
```

## ③ Reddit — r/incremental_games

> 규칙 확인 필수: 대부분의 인크리멘탈 서브는 자기홍보에 [Free]/[Windows] 등 태그와 "no monetization" 명시를 선호.
> 팬게임 IP 이슈가 있으니 **비상업·비수익 명시**가 안전판.

**Title:** `[Free][Windows/Mac] I made an idle Pokémon auto-battler that docks in the corner of your desktop`

```
Hi all — solo dev here. I got hooked on those tiny "docked at the edge of your screen"
idle games (Task Bar Hero style) and wanted one with Gen 1 Pokémon, so I built it.

**What it is**
A small window that sits in a corner of your desktop. A party of 3 auto-battles
through waves → route boss → regional champion → next region, forever. You come back
now and then to spend gold on upgrades, pull/fuse gear, and re-tune movesets.

**What's in it**
- All 151 Gen 1 species with real data (base stats, all 18 type matchups, movesets) — pulled from PokéAPI
- Gear system: 3 slots per Pokémon, gacha + fusion with a soft cap that rises as you progress
- Raids: build a 10-Pokémon team and match the boss's weaknesses — type synergy bonus for stacking a type
- Online leaderboards: stage progress + raid speedruns, with a weekly board so new players can place
- Collection: shinies (1% wild), IVs 0–31, Pokédex milestones
- Daily missions + streaks, offline gold, 8× battle speed

**Notes**
- Free, no ads, no monetization, no accounts. Non-commercial fan project.
- Windows and macOS. Progress is saved locally and survives updates; there's an export/import button for backups.
- macOS: it's unsigned, so you'll need `xattr -cr /Applications/PokemonBattleRoom.app` once.
- It was Korean-only until this week — I just added English, so if you spot awkward
  wording or an untranslated string, tell me and I'll patch it fast.

Download: https://github.com/lie-0022/pokemon-battle-room/releases/latest

Happy to answer anything about the balance math — getting an idle curve that doesn't
brick-wall at some point took a full redesign, and I wrote up what went wrong.
```

## 1. 화면 / UX 구조 — "작은 창"의 정체

- **항상 위(always-on-top) + 작업표시줄 도킹 + 아주 작은 창**. 일하는 화면 위에 얇게 얹혀 있고, 평소엔 거의 안 보다가 곁눈질로 본다.
- **전투는 철저히 1차원 가로 라인**: 몬스터가 **오른쪽(시스템 트레이 쪽)에서 스폰**되어 **왼쪽(시작 버튼 쪽)으로 행군**해 온다. 내 파티는 왼쪽에 자리 잡고 다가오는 적을 요격한다.
  - → 이 "가로 1D 라인"이 작은 창에 전투를 욱여넣는 핵심 트릭. 세로 공간이 거의 필요 없다.
- 본체 창은 좁고, **클릭하면 인벤토리/큐브/룬트리/스킬 등 패널이 열리는** 구조(별도 큰 창/오버레이로 추정).
- "게임이 알아서 돌아간다(the game plays itself)" — 자리를 비워도 진행, **여유로운 페이싱**.

> 💡 우리 적용점: 지금 우리 배틀룸의 "하단 도킹 가로 라인" 방향은 **정확히 맞다**. 다만 TBH는 적이 우→좌로 *행군*해 오는 웨이브 구조라 "전진하는 느낌"이 강하다. 우리도 단순 1:1이 아니라 **웨이브 행군 + 라인 요격**으로 가면 레퍼런스 감성에 가까워진다.

## 2. 핵심 게임 루프

```
파티 출전 → 자동으로 웨이브 전투 → 골드·XP·장비·상자 수집
   → 잡템은 연금(Alchemy)으로 골드화, 장비는 합성(Synthesis)으로 등급 ↑
   → 룬 트리 / 스킬 포인트 투자 → 다음 스테이지 푸시
   → Act 보스 farming 으로 고가치 전리품 → 스팀 마켓에 판매
```

이 루프가 **여러 시간 척도로 중첩**된다:
- **초 단위**: 적 처치 → 데미지/골드 팝업 (도파민)
- **분 단위**: 상자 개봉 → 장비 획득 → 더 강해짐
- **시간 단위**: 스테이지 돌파, 룬 노드 해금
- **일/주 단위**: Act 보스 farming, 마켓 거래, 만렙/프레스티지

> 💡 우리 적용점: 지금 우리 룸은 "초 단위(전투)"와 "분 단위(업그레이드)"만 있다. **시간 단위(스테이지/보스 게이트)와 장기 메타(영구 트리)** 가 빠져 단조롭게 느껴지는 것. 이 다층 루프를 채우는 게 재설계의 핵심.

## 3. 전투 시스템 (가장 깊은 부분)

### 3.1 스탯 계산 공식
```
최종 스탯 = (기본 + Σ고정치) × (1 + Σ가산%) × Π(1 + 각 곱연산%)
```
모디파이어 적용 순서: **기본 → 아이템 → 속성 → 패시브 → 계정상태(룬) → 상태이상 → 버프스킬 → 환경**

### 3.2 DPS / 치명타
```
DPS = 공격속도 × 공격력 × (1 + 치명확률 × (치명피해 − 1))
치명확률 = (기본치명 + 고정치명%) × (1 + 치명계수%)
```
- **치명확률·공격속도는 100% 초과(무제한) 가능**, 쿨감·저항·회피·블록은 **상한(capped)** 존재.

### 3.3 피해 경감 파이프라인 (들어오는 데미지 처리 순서)
1. **회피(Dodge/속성회피)** — 전부 무효
2. **블록(Block/속성블록)** — 데미지 절반
3. **저항(Resistance)** — 저항 −40당 받는 피해 +40%
4. **방어구(Armor)** — 체감 감소(diminishing), 타격·스테이지에 스케일
5. **데미지 감소(%)** — (1 − 값) 곱
6. **데미지 흡수(flat)** — 고정 차감
7. **바닥(Floor)** — 최소 1 보장

### 3.4 속성 & 상태이상 ★ (포켓몬과 직결)
- **속성(Element)**: 물리, 불(Fire), 냉기(Cold), 번개(Lightning), 카오스(Chaos), 전체(All)
- **전달 방식(Delivery)**: 근접, 투사체, 광역(AOE), 소환, 도트(DoT), 함정(Trap)
- **상태이상**:

| 상태이상 | 지속 | 효과 |
|---|---|---|
| Chill(냉기) | 4.0s | 공격·이동속도 −3% |
| Freeze(빙결) | 1.5s | 모든 행동 불가 |
| Ignite(점화) | 4.0s | 불 200 추가피해 |
| Shock(감전) | 6.0s | 번개 200 추가피해 |
| Bleed(출혈) | 7.0s | 물리 200 추가피해 |
| Stun(기절) | 2.0s | 받는 피해 +100 |

- **추적 스탯 63종**: 공격력/공격속도/치명확률/치명피해/체력/회복/저항(불·냉·번개·카오스)/방어/회피/블록/쿨감/이동속도/속성피해(불·냉·번개·물리) 등.

> 💡 우리 적용점: TBH의 "속성+상태이상"은 **포켓몬의 타입 상성 + 상태이상(마비·화상·독·빙결·수면)** 으로 거의 1:1 치환 가능. 우리는 이미 18타입 상성표를 갖고 있으니 **여기서 큰 차별화·깊이**를 만들 수 있다. (단, 63스탯 전부는 과함 — 핵심 8~12개만.)

## 4. 스테이지 / 진행 구조

- **총 120 스테이지 = 3 Act × 10 스테이지 × 4 난이도**
  - 난이도: **Normal(Lv1–32) → Nightmare(33–52) → Hell(53–77) → Torment(78–95)**
- **스테이지 내부 = 다수의 웨이브**: 1-1은 10웨이브, 1-6은 12웨이브… 난이도 오를수록 웨이브 증가(Normal 10~13 → Nightmare 22~23 → Torment 29~31).
- **Act 보스 = 각 Act의 X-10 스테이지** (예: 1-10 해골왕, 2-10 사막군주, 3-10 아콘 모르카르)
  - 보스 스테이지는 "웨이브 0", 보스만 등장. 보상 큼(예: 3,250 골드).
  - **Soul Stone(소울스톤) 필요** — 단, **성공 클리어 시에만 소모**(실패는 공짜 재도전).
- **마일스톤 보스**: 일정 웨이브마다(공략상 "매 100웨이브") 등장하는 거대 개체. **출힐로 못 버티는 DPS 체크 / 하드 기믹** — 준비 안 되면 아이들 진행이 *완전히 막힘*.
- **아이템 레벨 게이트**: "어떤 스테이지에 도달 = 그 레벨 아이템이 드랍 해금" (예: Lv5는 1-4, Lv20은 2-8, Lv35는 NM 1-3).
- **XP 최적화**: 캐릭터 레벨이 지역 레벨보다 6스테이지 이상 높으면 XP 패널티. **"X-9" 스테이지가 XP 효율 최적.**

> 💡 우리 적용점: 지금 우리는 "스테이지 = 무한 카운터" 뿐. TBH식 **Act/난이도/보스 게이트(소울스톤)/마일스톤 DPS체크**가 진행에 *구조와 목표*를 준다. 포켓몬으로는 **루트 → 체육관 관장(Act 보스) → 사천왕/챔피언(마일스톤) → 지방 이동(난이도)** 으로 번안하면 완벽하다.

## 8. Hero-dric Cube (제작·강화 허브)

- **영웅 Lv4에 해금**. 아이템을 먹여 큐브 자체가 레벨업하며 기능 해금. 고가치 아이템일수록 큐브 XP↑.

| 기능 | 해금 | 내용 |
|---|---|---|
| **Alchemy(연금)** | 초기 | 잡템 → 골드 + 큐브 XP (초반 주 골드원) |
| **Synthesis(합성)** | 초기 | **동일 등급 9개 → 다음 등급 1개** (결과 레벨은 드롭다운 선택) |
| **Craft(제작)** | Lv5 | 지정 레벨 범위에서 랜덤 장비/장신구 생성 (초반 장신구 주공급) |
| **Decoration(장식)** | Lv8 | Rare+ 장비에 단일스탯 젬 소켓 |
| **Removal(추출)** | Lv10 | 소켓 제거(골드 비용, 재료 파괴) |
| **Sculpture(조각/각인)** | Lv15 | Immortal+ 장비에 몬스터재료 각인(2스탯) |
| **Wish(소원)** | Lv20 | 애니버서리 코인으로 랜덤 레어드랍 |
| **Inscription(명문)** | Lv25 | 스크롤로 Arcana+ 장비에 랜덤 스탯 1개 추가 |

## 12. "왜 재미있는가" — 설계 원리 7가지 (★재설계의 나침반)

1. **저관여·고성장(idle)**: 안 봐도 진행. "켜두면 보상"이 죄책감 없는 백그라운드 동반자를 만든다.
2. **다층 보상 루프**: 초(데미지팝업)·분(상자/장비)·시간(스테이지/룬)·일(보스/거래)이 중첩 → 어느 순간에 봐도 "방금 뭔가 좋아졌다".
3. **마일스톤 DPS 체크(벽)**: 무한 진행에 *구조적 정체*를 박아, "더 강해져야 할 명확한 이유"를 만든다. → 빌드를 고민하게 함.
4. **빌드 깊이**: 63스탯 × 소켓 × 스킬 × 룬 → "내 캐릭을 내가 설계"하는 표현 욕구 충족.
5. **계정 영구 진행(룬)**: 한 판이 끝나도 *영원히 남는* 성장 → 장기 동기.
6. **수집 그라인드 훅**: 5,000킬 펫, 10등급 아이템, 5,760개 도감 → "다 모으고 싶다".
7. **마찰 제거**: 자동 재도전·자동 상자개봉·블루 포털 fast-travel → 귀찮음을 계속 깎아준다.

> **우리 룸이 단조로운 이유 진단**: 위 7개 중 우리는 **1(idle)·2의 일부(초·분)** 만 있다.
> 빠진 것 = **마일스톤 벽(3), 빌드 깊이(4), 영구 메타(5), 수집 훅(6)**. 재설계는 이 4개를 채우는 방향.

## 14. 재설계 방향 제언 (요약)

**구조를 갈아엎을 때 우선순위 (위 7원리 기준):**

1. **파티 3마리 동시 전투** (탱/딜/서포트 역할) — 가장 큰 체감 변화.
2. **루트/스테이지 + 체육관 보스 게이트 + 사천왕 마일스톤** — 진행에 목표와 벽.
3. **계정 영구 진행 트리**(트레이너 능력 + 도감 보너스) — 장기 동기, 단조로움 해소.
4. **기술 쿨다운 자동전투 + 타입 상성·상태이상** — 전투 깊이.
5. **합성/강화(9→1) + 레어리티 수집** — 수집·강화 도파민.
6. **마찰 제거**(자동 회복/진행/빠른 이동) + 오프라인 보상 강화.

> 세부 시스템 설계와 데이터 모델은 다음 문서(`02-배틀룸-재설계.md`)에서.

## 0. 한 줄 컨셉

> **"파티 포켓몬에게 실제 도구(구애머리띠·생명의구슬·먹다남은음식…)를 들려주고, 더 좋은 도구를 파밍·강화·합성하며 깊은 곳까지 진행하는 아이들 RPG."**
> TBH의 "장비 드롭→장착→강해짐→더 깊이" 루프를, **장비 = 포켓몬 지닌도구**로 번안.

## 1. 기존과 무엇이 달라지나 (갈아엎는 지점)

| | 지금(폐기) | 새 설계 |
|---|---|---|
| 장비 정체 | generic 무기/방어구/장신구 (가짜) | **실제 포켓몬 도구** (구애머리띠 등) |
| 슬롯 | 마리당 3슬롯(무기/방어구/장신구) | **마리당 지닌도구 1칸**(원작 충실) + 공유 **소모품 가방** |
| 성장 주축 | 레벨·업그레이드 위주, 장비는 곁다리 | **도구가 주력 성장축** (레벨은 보조) |
| 등급 | 색만 다른 5등급 | **★ 강화 등급**(효과 배율) + 희귀 도구 |
| 데이터 | 코드 내 가짜 생성 | **items.json**(PokéAPI 실데이터: 한글명·아이콘·분류) |

**그대로 가져가는 검증된 부분**(02에서): 파티 3마리 동시 오토배틀, 진행 구조(지방→루트→보스→챔피언→배지), 트레이너 트리🌳, 도감📖, 상태이상/타입상성. → 전투/진행 뼈대는 유지, **장비·경제 레이어만 새로 짓는다.**

## 2. 핵심 설계 결정

1. **지닌도구 1칸 / 마리** — 원작 충실(포켓몬은 도구 1개만 보유). 깊이는 *파티 6마리 × 각자 최적 도구 × ★등급 × 소모품 운용*에서 나온다.
2. **도구가 주 성장축** — 도구 효과를 크게(예: +50% 공격) 잡아, "어떤 도구를 누구에게" 가 핵심 의사결정이 되게.
3. **★ 강화 등급(★1~★5)** — 같은 도구도 ★에 따라 효과 배율↑. 드롭은 랜덤 ★, **중복 합성(같은 도구 3개→★+1)** 으로 키움 = 파밍 훅.
4. **소모품은 별도 가방** — 나무열매(자동 발동)·몬스터볼(포획)·진화의돌(진화)은 장착이 아니라 *전투 중 자동/수동 소모*.
5. **실데이터** — `build-items.js`로 PokéAPI에서 도구 한글명·아이콘·분류를 받아 `items.json` 생성(= `pokedex.json`과 동일 방식).

## 3. 아이템 분류 (실제 포켓몬 도구 → 게임 효과)

### 3-A. 지닌도구 (장착형 — 마리당 1칸)

| 도구 | 분류 | 게임 효과(★1 기준 → ★5) | 역할 |
|---|---|---|---|
| **구애머리띠** | 공격 | 물리공격 +30%→+60% (기술 1개 고정) | 물리 딜러 |
| **구애안경** | 공격 | 특수공격 +30%→+60% (기술 1개 고정) | 특수 딜러 |
| **구애스카프** | 속도 | 스피드 +30%→+60% (기술 1개 고정) | 선공/속공 |
| **생명의구슬** | 공격 | 모든 공격 +20%→+40%, 매턴 자해 소량 | 고위험 딜 |
| **힘의머리띠** | 공격 | 물리 위력 +8%→+16% | 안정 딜 |
| **달인의띠** | 공격 | 효과굉장(상성2배) 시 위력 +15%→+30% | 상성 특화 |
| **○○플레이트/구슬** | 타입강화 | 해당 타입 기술 위력 +12%→+24% | 단일타입 특화 |
| **먹다남은음식** | 생존 | 매턴 최대HP 4%→8% 회복 | 지속 탱 |
| **돌격조끼** | 생존 | 특수방어 +25%→+50% | 특수 탱 |
| **진화의휘석** | 생존 | *미진화* 한정 방어·특방 +25%→+50% | 초반 탱 |
| **기합의띠** | 생존 | 풀피일 때 치명타/일격 1회 버팀(HP1) | 생존 보험 |
| **조개껍질방울** | 생존 | 준 데미지의 8%→16% 흡혈 | 자힐 딜 |
| **울퉁불퉁멧** | 생존 | 피격(근접) 시 가시 반사뎀 | 반사 탱 |
| **초점렌즈** | 치명 | 치명확률 +8%→+20% | 치명 빌드 |
| **광각렌즈** | 명중 | 명중·빗나감 방지 +(상태이상 적중률↑) | 안정/디버프 |
| **선제공격손톱** | 유틸 | 확률(10%→25%)로 그 턴 선공 | 변수 |
| **왕의징표석** | 유틸 | 공격 시 확률로 상대 풀죽음(행동불가) | 봉쇄 |

> ★등급 = **효과 배율 + 희귀도**. 구애·생명의구슬·왕의징표석 등 강력 도구는 드롭 확률↓.

### 3-B. 소모품 (가방 — 자동/수동)

| 도구 | 효과 |
|---|---|
| **오랭열매 / 자뭉열매** | 보유 포켓몬 HP 위기 시 **자동** 회복(소량/대량) |
| **리샘열매** | 상태이상 시 **자동** 치료 |
| **캄라열매** | HP 위기 시 **자동** 스피드 급상승 |
| **몬스터볼 / 하이퍼볼 / 마스터볼** | 야생/보스에게 사용 → **포획**(파티·도감 추가), 등급별 포획률 |
| **불꽃의돌·천둥의돌·물의돌·리프의돌·달의돌** | 해당 포켓몬 **즉시 진화** (레벨 진화 외) |

## 4. ★ 강화 / 합성 (파밍 훅)

- 드롭 시 ★는 깊이(지방/보스)에 따라 가중: 초반 ★1~2, 보스 ★2~3, 챔피언 ★3~4, 희귀 ★5.
- **합성**: 동일 도구 **3개 → 같은 도구 ★+1** 1개 (TBH의 9→1 합성 축소판).
- **분해**: 안 쓰는 도구 → 골드 + 소량 **강화가루**(★ 강제 상승에 사용 — 선택 시스템).
- → "쓰레기 도구도 분해/합성 재료" 라 버릴 게 없음 = 지속 파밍 동기.

## 5. 핵심 루프

```
전투(자동) → 적 처치 → 골드 + 도구 드롭(🎁)
  → 가방에서 더 좋은 도구/높은 ★를 파티에 장착
  → 중복은 합성(★↑), 잡템은 분해/판매
  → 강해진 파티로 루트 보스·챔피언 격파 → 다음 지방(난이도↑) → 더 좋은 도구 풀 해금
  → 몬스터볼로 새 포켓몬 포획(도감·파티 확장), 진화의돌로 즉시 진화
```
TBH 7대 재미요소 매핑: ①idle ②다층보상(도구드롭=분단위 도파민) ③보스 벽 ④빌드 깊이(도구×포켓몬×타입) ⑤영구 메타(트리·배지) ⑥수집(도구 도감+포켓몬 도감) ⑦마찰 제거(자동 회복/진행).

## 7. 상태 모델 (state v6 — 깨끗하게 재정의)

```js
state = {
  version: 6,
  gold, dust,                    // dust = 강화가루
  started,                       // 캐릭터 선택 완료 여부
  party: [ { en, lv, xp, item } ],   // item = 장착 도구의 uid (또는 null)
  bag: {                         // 도구 인벤토리
    gear: [ {uid, key, star} ],  // 장착형 도구 (key=아이템키, star=★)
    consum: { 'oran-berry': n, 'poke-ball': n, ... }   // 소모품은 수량
  },
  up, trainer, dex, prog,        // 02에서 유지(업그레이드·트리·도감·진행)
  settings: { battleSpeed, autoCatch },
  lastSeen,
}
```

- `party[i].item` 은 `bag.gear` 의 uid 참조(장착). 합성/분해 시 정리.
- 파생 전투스탯 = 종족값×레벨 × 트리/배지 × **장착 도구 효과(키+★ 기반)**.

## 8. 데이터: `build-items.js` (PokéAPI → items.json)

- `pokedex.json` 만든 방식 그대로, 아이템도 실데이터로:
  - 각 도구: `key`(영문), `name`(한글), `category`, `sprite`(아이콘 URL), `role`/`effect`(게임 효과는 코드 정의 테이블에서 매핑)
  - 아이콘: `https://raw.githubusercontent.com/PokeAPI/sprites/master/sprites/items/{key}.png` (스프라이트 존재 확인 후 사용)
- 게임 효과 수치는 코드의 `ITEM_EFFECTS` 테이블에서 정의(밸런스 조정 용이), 이름/아이콘/분류만 실데이터.

## 9. 빌드 단계 (재구축 순서)

- **R1. 데이터 토대** — `build-items.js`로 도구 실데이터(한글명·아이콘) 수집 → `items.json` + `ITEM_EFFECTS` 테이블 정의.
- **R2. 장비 레이어 교체** — 기존 generic 무기/방어구/장신구 제거 → **지닌도구 1칸** 모델로 교체, 파생 스탯에 도구 효과 반영, 머리 위 도구 아이콘 표시.
- **R3. 가방 패널 재작성** — 장비 탭(장착/해제/합성/분해) + 소모품 탭.
- **R4. 드롭/상점 재작성** — 도구 드롭(★ 가중), 상점 뽑기·판매, 분해.
- **R5. 소모품 동작** — 나무열매 자동발동, 몬스터볼 포획, 진화의돌 진화.
- **R6. 폴리시·밸런스** — 도구 효과 밸런스, 연출, 도구 도감.

각 단계는 독립 실행/테스트 가능하게. (현재 전투·진행·트리·도감은 살아있는 채로 위에 얹음.)

## 10. 확정 결정 (2026-06-26)

1. **슬롯 수 = 3칸 (장비 다닥다닥)** — 단, 의미 없는 중복 방지 위해 **카테고리형 3슬롯**:
   - **메인** : 구애머리띠/안경/스카프·생명의구슬·먹다남은음식·돌격조끼·진화의휘석·기합의띠·조개껍질방울 (핵심 스탯/지속)
   - **강화** : ○○플레이트(타입)·힘의머리띠·달인의띠 (위력/타입 증폭)
   - **정밀** : 초점렌즈·광각렌즈·선제공격손톱·왕의징표석·울퉁불퉁멧 (치명/명중/유틸)
   - → 마리당 3칸 = 메인+강화+정밀 한 개씩. TBH식 "장비 다닥다닥" + 슬롯별 역할 구분.
2. **포획 = 가볍게(보너스)** — 몬스터볼 포획은 가끔의 보너스/도감 채우기. 주 재미는 장비 파밍.
3. **소모품 = 전부 자동** — 나무열매·회복은 위기 시 자동 발동(아이들 친화).

- 아이콘: PokéAPI 아이템 스프라이트 20종 존재 확인 → 실아이콘 사용.

## 11. 구현 메모
- 슬롯 3칸이므로 state: `party[i].equip = { main, boost, tech }` (각 {key, star}|null).

- R5 소모품(나무열매 자동·볼 포획·진화의돌)은 장비 코어 다음 단계.

## 12. 구현 로그 — v7 (실제 RPG 시스템) 2026-06-26
데이터: `build-learnsets.js` → `gamedata.json/js` (기술 262종 물리/특수/타입/한글, 151마리 레벨업 러닝셋, TM 45종).
- ✅ **멤버 모델**: 각 포켓몬 `learned`(배운 기술)·`active`(세팅 4기술)·`equip`.

- ✅ **타입 스마트 AI**: `bestMoveKey()` — 세팅 기술 중 `위력×자속×상성` 최대를 자동 선택(상대 타입 따라).
- ✅ **레벨업 학습**: `checkLearn()` — 레벨 도달 시 러닝셋 기술 자동 습득(빈 슬롯이면 자동 세팅).
- ✅ **포획**: 야생 처치 10% → 벤치 보유 추가(중복 제외). `🦸 패널`에서 파티(최대 maxParty)에 편성.
- ✅ **기술 세팅 UI**: 🦸 패널 — 멤버 선택 → 능력치·세팅4·배운기술 토글·TM 학습.
- ✅ **기술머신**: 전투 드롭(웨이브5%/보스30%) → `state.tms` → 배울 수 있는 포켓몬에게 학습.
- ✅ 진화(레벨)·장비 3슬롯·트리·도감·상태이상 유지.

## 21. 도구·진화 시스템 감사 + 전면 수정 (2026-06-29, 3에이전트 병렬 감사 기반)
### 도구(장비) 현황·문제·수정
- **현황**: ITEM_DEFS 18메인+5강화(+17플레이트)+5정밀. 효과는 effVal→gearStat(합산)/gearMax(최대)/gearTypeBoost/gearSuperEff/hasSash로 읽혀 offMult·mMaxHp·mInterval·heroAttack·calcDamage에서 작동.
- **핵심 문제**: `offMult`가 physAtk·specAtk **양쪽**에 곱해져, atk부스트 4종(구애머리띠/구애안경/생명의구슬/힘의머리띠)이 **물리·특수 구분 없이 동일**. → 아이템 차별성 상실.
- **수정**:
  - eff 키 분리: `physAtk`(물리 전용)·`specAtk`(특수 전용)·`offMult`(양쪽). 구애머리띠=physAtk 0.35, 구애안경=specAtk 0.35, 생명의구슬=offMult 0.25, 힘의머리띠=physAtk(약), **지식의안경(wise-glasses) 신규**=specAtk(약, 강화슬롯).
  - `offMult`는 offMult·업글·배지만, `physAtk()`/`specAtk()`에 각각 `gearStat(physAtk/specAtk)` 곱. `gearLabel`에 물리공격/특수공격/공격 라벨, `gearScore`는 물리형/특수형(stats.atk≥spa)에 맞춰 가중 → 자동장착이 역할별로 고름.
  - lifesteal/flinch/thorns: gearMax→gearStat(합산, 다중 장착 시너지).

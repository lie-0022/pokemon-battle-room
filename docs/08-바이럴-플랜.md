# 08. 바이럴 플랜 (2026-07 리서치 기반)

> 목표: 유저 최대화. 6각도 웹 리서치(어나더레드·포켓로그·국내 자작게임 사례·스트리머 시딩·제품 내 바이럴 장치·커뮤니티 규정) 결과를 실행 계획으로 압축.
> 핵심 결론: **국내 포켓몬 팬게임의 확산 공식 = ① 커뮤니티 씨앗 글 → ② 중소 포켓몬 스트리머 픽업 → ③ 대형 확산 → ④ 위키/후기 인프라가 받아냄.** 광고가 아니라 "스트리머가 방송하고 싶은 게임"인지가 결정적.

---

## 1. 레퍼런스 핵심 (검증된 사실)

### 어나더레드 (21만 DL, 12주)
- 최초 공개가 **스트리머(눈파티) 팬카페에 소개글+드라이브 링크** — 타깃 시딩 그 자체.
- 공개 9일 후 **윤가놈**(치지직 포켓몬 전문)이 첫 방송 → 눈파티 → 시라유키 히나 → 따효니·플레임 등 대형 확산.
- 제작자가 **방송 채팅에 실시간 참여 + 즉석 패치**(벌레타입 챌린지용 전용 빌드까지) → "소통하는 제작자" 자체가 방송 콘텐츠.
- 게임 안에 스트리머 카메오·밈 재현 → 팬덤이 자발 확산.
- 다운로드 **공개 카운터** 수치가 그대로 기사화("21만 DL"). 언론은 스트리머 화제 → 커뮤니티 확산 → 수치 공개 이후에 따라옴.
- 공개 후 **7주 고밀도 업데이트**로 스트리머 재방문(2회차 방송) 유발.
- 디스코드/홈페이지 없이도 성공 — 커뮤니티 글 모니터링→빠른 패치가 소통 창구.
- 반복 문구: **"한글 되는 웰메이드 팬게임은 귀하다"**.
- 교훈(병목): 구글드라이브 용량 초과로 다운로드 대란 → 바이럴 순간엔 깃허브가 안전.

### 포켓로그 (월 방문 850만→5,380만)
- **무설치 웹 + 한국어화와 동시에** 방송인 다발 픽업(침착맨·옥냥이 같은 날 시작)이 기폭제.
- 스트리머 간 실력 비교("옥냥이 1트클 vs 침착맨 무한도전")가 밈 연료.
- 디시 갤러리가 한국어판보다 3일 먼저 생김 — 커뮤니티 인프라 선행.
- **데일리 시드런**(전원 같은 시드 24시간 경쟁)이 "오늘 것 몇 점?" 공통 화제 생성.
- 유행 유효기간 약 2개월 — 그 안에 붙잡을 리텐션 장치 필요.

### 기타 국내 사례
- 산나비: 무료 데모 → 커뮤니티 후기 → 실황 순서. "무료로 먼저 만져보게" 검증됨.
- 트릭컬: 개발자가 커뮤니티 밈에 직접 올라타 판을 깔아줌 → 역주행.
- 왁제이맥스: **음원 저작권으로 65억 청구** — 무료 팬게임도 법적 리스크 실존. BGM 등 외부 저작물 절대 금지.
- 커뮤니티 글 문화: 일회성 홍보글이 아니라 **"버전업마다 후속글 + 갱신형 현황글"** 연재가 표준.

### Wordle/방치형 공유 장치
- Wordle 폭발 = 퍼즐이 아니라 **스포일러 없는 이모지 공유 버튼**(90만→200만/주). 공유 텍스트에 **링크를 뺀 것**이 오히려 확산 요인(광고 티 제거, 검색 유입).
- 스트릭 = 손실 회피(Duolingo 커밋 +60%). 스트릭 보호권은 이탈 21% 감소.
- 포켓몬 커뮤니티엔 **이로치 인증 문화**가 확고 — 인증글은 자동 주목.

## 3. 스트리머 시딩 (2단계에서)

- **1순위**: 포켓몬 전문 중소 — **윤가놈, 눈파티, 에투샤, 안모리** (+ 박세준·김용녀). 어나더레드도 중소→대형 순서로 번짐.
- **최적 제보처**: 유튜버 **'팔로'** — 포켓몬 팬게임 Top10 큐레이션을 정기 제작. "한국산 1인 개발+온라인 랭킹 내장 방치형"은 리스트에 없던 유형이라 소개 명분 뚜렷.
- 접촉: 각 채널 팬카페/치지직 커뮤니티(규정 확인 후) 또는 유튜브 정보 탭 이메일.
- 제보문 필수 문구: **"방송·영상화·수익창출 전면 허용, 무료·비영리 팬게임"** (저작권 부담 선제 해소).
- 훅: ① 방치형이라 **방송 켜두고 다른 콘텐츠 진행 가능** ② **시청자와 같은 랭킹판 경쟁**(어나더레드에 없던 무기) ③ 요청 시 전용 챌린지 빌드 즉석 제작.
- 픽업 시: 채팅 참여 + 피드백 즉석 패치(우리 1인+CI 구조로 재현 가능).
- 타이밍: 봉켓몬 64인 서버(7/1 종료) 직후 = 치지직 포켓몬 열기 검증된 상태. 팟벤 공개 명단 64명 = 접촉 후보 풀.

## 5. 실행 순서

**즉시 (이번 주)**
1. 아카 후속글: "v1.3.1 일일 미션 업데이트" 연재 시작 (저녁 19~23시, GIF 첨부)
2. 루리웹 `[자작][무료/비상업]` 출시글 + 디시 인디갤 가이드 준수 홍보글 1회 + game_dev 개발일지 1화
3. '팔로' 채널 제보 (팬게임 Top10 후보)
4. 운영 원칙 가동: 커뮤니티 제보 → 24시간 내 패치 + 제보자 닉네임 패치노트

**단기 (1~2주)**
5. 결과 복사 버튼·주간 랭킹 리셋·스트릭 구현 → v1.4 "경쟁 시즌" 업데이트
6. 중소 스트리머 4인 시딩 (전용 제보문, 규정 확인 후)
7. 주 1회 이상 눈에 보이는 업데이트 6주 지속 (재방문 방송 유발)

**중기 (3~6주)**
8. 일일 시드런 + 이로치 인증 카드 → v1.5
9. 아카 "주간 랭킹 1위 인증" 이벤트 (대회 탭 문화 활용)
10. 다운로드 마일스톤 글 → 기사화 소재 축적

**전제/리스크**
- **저장소 공개** 필요: 깃허브 다운로드(드라이브 병목 대비) + 웹 버전(포케로그가 증명한 최강 포맷, "컴으로만 가능?" 수요 실측됨)
- **절대 금지**: 수익화·후원 링크(아카 차단+왁제이맥스 65억 선례), 외부 음원, 유저인 척 바이럴, AI 티 나는 홍보 문구

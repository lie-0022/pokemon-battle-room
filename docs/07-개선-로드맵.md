## 1단계 — 유저 이탈 방지 (즉시) ✅ 2026-07-16 완료
1. **인앱 업데이트 알림**: GitHub releases API를 6시간마다 체크, 새 버전이면 상단바에 `🔄 vX.Y.Z` 배지 → 클릭 시 릴리스 페이지. `GAME_VERSION` 상수 기준(릴리스마다 버전 갱신 — 배포 프로토콜에 반영).
2. **세이브 내보내기/가져오기**: 🗺 로드맵 패널 하단 "데이터" 섹션. 내보내기=JSON 파일 다운로드, 가져오기=파일 선택→검증→확인→적용·재시작.
3. **외부 링크 처리**: main.js setWindowOpenHandler → 기본 브라우저로 열기(shell.openExternal).

## 2단계 — 웹 버전 (설치 장벽 제거)
- room.html + 에셋을 **GitHub Pages로 호스팅** → 링크 클릭만으로 플레이(모바일 브라우저 포함).
- Electron 전용 UI(리사이즈 그립 등) 웹에서 숨김, 모바일 뷰포트/터치 점검.
- 세이브는 localStorage(브라우저별 독립) — 1단계의 내보내기/가져오기로 데스크톱↔웹 이사 지원.
- 커뮤니티 글에 "웹에서 바로 해보기" 링크 추가 → 다운로드 전환율↑.
